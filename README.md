## Overview

iZotope Vinyl simulates the full analog signal chain of vinyl playback: needle dust, scratching, wear, warp, electrical hum, and the mechanical noise of a record player spindle.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **iZotope Vinyl** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Needle Dust** | Simulate dust accumulation on the needle stylus over time |
| **Warp Simulation** | Vinyl warping pitch modulation from temperature-simulated disc flex |
| **Electrical Hum** | 60Hz and 50Hz power hum injection with configurable level |
| **Year Control** | Single knob ages the vinyl from fresh pressing to heavily worn |
